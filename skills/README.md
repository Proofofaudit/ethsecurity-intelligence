# Research skills

Generated by `npm run skills:build` from dataset 20261126T130839Z-fe7ea363+fa515294 (brief 2026.11-lab-v1). Do not edit by hand; change lib/skills and regenerate.

Each folder holds a `SKILL.md` for assistants that support skills and a `config.json` with the same parameters, the matching initiatives, the MCP connection, the JSON Schema for structured output and empty provenance fields. Every brief restricts research to the 55 initiatives in the ballot cohort, requires source citations, treats retrieved content as untrusted, never presents future targets as existing capabilities, sets no ranking weights and leaves decisions to the reviewer.

ETHSecurity Intelligence runs no AI model. These files instruct the reviewer's own assistant.

## MCP connection

These files were generated with site URL http://localhost:3000. That is a local server (`npm run build && npm start`); regenerate with `NEXT_PUBLIC_SITE_URL=<deployment URL> npm run skills:build` for a deployment.

- Remote (Streamable HTTP, stateless, read-only): http://localhost:3000/api/mcp
- Local (stdio): `npm run --silent --prefix /path/to/ethsecurity-intelligence mcp`. Local stdio server from a clone of the repository (after npm ci). It reads data/published/dataset.json, or MongoDB when MONGODB_URI is set in the environment.

Claude Desktop (local stdio), `claude_desktop_config.json`:

```
{
  "mcpServers": {
    "ethsecurity-intelligence": {
      "command": "npm",
      "args": [
        "run",
        "--silent",
        "--prefix",
        "/path/to/ethsecurity-intelligence",
        "mcp"
      ]
    }
  }
}
```

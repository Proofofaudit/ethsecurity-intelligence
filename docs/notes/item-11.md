# Item 11: Open questions (notes for the docs merge)

A question is not an accusation and not a finding that something is wrong. Questions come from structural gaps in official fields (and, for rules 4 and 8, official text and extracted claims). Nothing is generated by AI. Missing information is "Not found", never a negative finding. The same templates apply to every initiative.

Module: `lib/intelligence/open-questions.ts` (`openQuestions`, `OPEN_QUESTION_RULES`, `OPEN_QUESTION_CATEGORIES`, `OPEN_QUESTION_NOTICE`, `countByCategory`, `questionsAsText`). Service: `openQuestionsFor`, `openQuestionRows` in `lib/intelligence/service.ts`. UI: `components/dossier/open-questions.tsx`, `app/research/questions/page.tsx`.

Local state: "Mark as asked or resolved" is stored in the private workspace (`localStorage` key `esi.workspace`, field `openQuestions`, keyed by stable question id, schema `OpenQuestionMarks` in `components/workspace/schema.ts`). "Copy as list" copies plain text. No code in this feature sends questions anywhere; `tests/unit/open-questions.test.ts` ("no outreach") asserts this.
